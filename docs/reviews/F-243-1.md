## Escalated to the owner

**Round 2 stopped the loop** (the runner's rule: F-243-1-D1-02 found not fixed two rounds running while the issues went 2, then 3).

- **What is unresolved:** nothing known. Every finding of rounds 1 and 2 is fixed with a regression test that fails without the fix (commit c91ba46); no review has checked the round 2 fixes yet.
- **The cause:** D1-02 is one design point, "which version of a list is shown", and each review found another way a damaged or odd copy of an AER file could pass for a good one (a reader upgrade, a copy cut short, a page in another layout, a partly read list). Each was fixed case by case.
- **Claude's change of approach:** one simpler rule instead of more cases: a list is shown only when it was read whole (its structure, every page's columns and its end line found, and every record read). Anything else is kept and logged, never shown, until the reader is fixed. All 14 real files read whole today.
- **Codex's view:** needs-attention on round 2, for the three findings above, since fixed.
- **The decision needed:** allow round 3 (rounds 3 to 5 remain within the normal limit of 5), with the simpler rule; or stop here.
